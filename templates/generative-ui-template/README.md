# Generative UI Template for AG2

This template provides a complete framework and boilerplate for building Generative UI applications that integrate agentic AI workflows using AG2 (formerly AutoGen).

## What is Generative UI?

Generative UI is a paradigm where the user interface is dynamically generated by AI agents based on context, user needs, and application state. Instead of static UI components, the interface adapts and evolves through AI-driven decisions.

## Features

This template includes:

- **🤖 AG2 Agent Integration**: Pre-configured conversable agents with tool support
- **🎨 Dynamic UI Generation**: Components that render based on agent responses
- **🔄 Real-time Communication**: WebSocket support for live agent interactions
- **📦 Complete Boilerplate**: FastAPI backend + Modern frontend setup
- **🔧 DevContainer Ready**: One-click setup with GitHub Codespaces
- **📝 Example Workflows**: Common patterns for generative UI applications

## Quick Start

### Prerequisites

- Python 3.10+ (3.11 recommended)
- Node.js 18+ (for frontend tooling)
- An OpenAI API key or compatible LLM provider

### Setup with GitHub Codespaces

1. Click "Code" → "Create codespace on main"
2. Wait for the environment to initialize
3. Set your API keys in the codespace secrets or `.env` file
4. Run `python backend/main.py`
5. Open the preview URL to see your Generative UI app

### Local Setup

1. **Clone and navigate to this template:**
   ```bash
   cd templates/generative-ui-template
   ```

2. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Install frontend dependencies (if using advanced UI):**
   ```bash
   cd frontend && npm install
   ```

4. **Configure your API keys:**
   Create a `.env` file or set environment variables:
   ```bash
   export OPENAI_API_KEY="your-api-key-here"
   ```

   Or create an `OAI_CONFIG_LIST` file:
   ```json
   [
     {
       "model": "gpt-4",
       "api_key": "your-api-key-here"
     }
   ]
   ```

5. **Run the application:**
   ```bash
   python backend/main.py
   ```

6. **Open your browser:**
   Navigate to `http://localhost:8000`

## Core Concepts

### 1. Agent-Driven UI Generation

Agents analyze user input and application state to generate appropriate UI components:

```python
from autogen import ConversableAgent

ui_agent = ConversableAgent(
    name="ui_generator",
    system_message="Generate UI components based on user needs",
    llm_config=llm_config,
)
```

### 2. Real-time Communication

WebSocket integration allows for live updates:

```javascript
const ws = new WebSocket('ws://localhost:8000/ws');
ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    renderGeneratedUI(data.ui_components);
};
```

### 3. Tool Integration

Agents can call tools to fetch data, perform actions, and generate UI:

```python
@ui_agent.register_for_llm(description="Generate a form UI")
def generate_form(fields: List[str]) -> dict:
    return {
        "type": "form",
        "fields": fields
    }
```

## Customization

### Adding New Agents

1. Create agent definition in `agents/`
2. Register tools and capabilities
3. Integrate with UI generation logic in `backend/ui_generator.py`

### Modifying UI Templates

1. Edit HTML templates in `frontend/templates/`
2. Update CSS in `frontend/static/css/`
3. Enhance JavaScript logic in `frontend/static/js/`

### Configuring LLM Providers

The template supports multiple LLM providers:
- OpenAI (GPT-4, GPT-3.5)
- Azure OpenAI
- Anthropic Claude
- Google Gemini
- Local models via Ollama

Update your `OAI_CONFIG_LIST` or environment variables accordingly.

## Best Practices

1. **Stateless UI Generation**: Keep UI generation logic pure and deterministic
2. **Error Handling**: Gracefully handle agent failures and fallback to default UI
3. **Performance**: Cache generated UI components when appropriate
4. **Security**: Validate and sanitize all agent-generated content
5. **Testing**: Test agent behaviors with various inputs
